# 作业管理器 — UI 设计规范

## 设计原则

- **简洁**：信息层级清晰，操作路径短
- **直观**：按钮和状态一目了然，新手无需学习
- **友好**：淡蓝色主调给人平静、有条理的感觉

## 颜色方案

### 主色调

| 用途 | 色值 | 预览 |
|------|------|------|
| 主色 | `#5B9BD5` | 淡蓝 |
| 主色悬停 | `#4A8AC4` | 深蓝 |
| 背景色 | `#F0F6FB` | 极浅蓝 |
| 卡片背景 | `#FFFFFF` | 白色 |
| 文字主色 | `#2C3E50` | 深灰蓝 |
| 文字次要 | `#7F8C8D` | 灰色 |
| 边框色 | `#DCDFE6` | 浅灰 |

### 功能色

| 用途 | 色值 | 预览 |
|------|------|------|
| 高重要性 | `#E74C3C` | 红色 |
| 中重要性 | `#F39C12` | 橙色 |
| 低重要性 | `#27AE60` | 绿色 |
| 成功/完成 | `#27AE60` | 绿色 |
| 危险/删除 | `#E74C3C` | 红色 |
| 置顶标记 | `#5B9BD5` | 淡蓝 |

### 状态色

| 状态 | 效果 |
|------|------|
| 已完成卡片 | 透明度 0.6 + 文字删除线 |
| 置顶卡片 | 左边框 4px 实线 `#5B9BD5` |
| 过期未完成 | DDL 文字显示红色 |

## 组件规格

### 标题栏
- 高度：自适应，内边距 16px 0
- 背景：白色 + 底部细边框
- 内容：应用标题（左对齐），副标题可选

### 操作栏
- 添加按钮：主色背景 + 白色文字，圆角 6px
- 搜索框：白色背景 + 浅灰边框，圆角 6px，左侧搜索图标

### 作业卡片
- 白色背景，圆角 8px，浅阴影
- 科目以粗体显示在左侧
- 重要性标签为彩色小圆点 + 文字
- DDL 以等宽字体显示
- 操作按钮排列在卡片底部

### 添加模态框
- 居中弹出，半透明黑色遮罩
- 白色背景，圆角 12px
- 表单纵向排列
- 底部"取消"和"确认添加"按钮

### 按钮
- 主按钮：主色背景，白色文字
- 次要按钮：白底 + 主色边框
- 危险按钮：白底 + 红色边框
- 小图标按钮：无背景，hover 变色

## 响应式设计

- 桌面端：最大宽度 640px，居中显示
- 移动端（< 480px）：边距缩小至 12px，卡片内边距 12px
- 按钮触摸目标：至少 44px × 44px
