# 作业管理器 — 需求文档

## 项目概述

一款运行在浏览器中的本地作业管理器，帮助用户记录和追踪各科目作业的截止日期（DDL）。

## 功能需求

### F1. 添加作业
- 输入项：科目（必填）、具体内容（必填）、截止日期 DDL（必填）、重要性（选填，默认"中"）
- 重要性分为三档：高 / 中 / 低
- 截止日期格式：YYYY-MM-DD

### F2. 作业列表
- 以卡片形式展示所有作业
- 排序规则：置顶作业在最上 → 其余按 DDL 升序（早截止的在前）
- 已完成作业排在同级末尾

### F3. 状态管理
- 每项作业有"完成"和"未完成"两种状态
- 可一键切换状态
- 已完成作业显示删除线和半透明样式

### F4. 置顶管理
- 可将作业置顶或取消置顶
- 置顶作业始终位于列表最上方（无视排序规则）

### F5. 删除作业
- 可删除任意作业
- 删除前需确认

### F6. 搜索功能
- 按关键字实时过滤作业列表
- 匹配范围：科目名称 + 具体内容
- 大小写不敏感

### F7. 数据持久化
- 使用浏览器 localStorage 存储数据
- 刷新页面或关闭浏览器后数据不丢失
- 后续可扩展云同步

## 非功能需求

### NF1. UI 设计
- 简洁直观，适合初学者使用
- 主色调：淡蓝色（#5B9BD5）
- 布局清晰，信息层级分明

### NF2. 运行环境
- 支持现代浏览器（Chrome、Safari、Edge、Firefox）
- 无需安装任何软件，双击 HTML 文件即可使用

### NF3. 技术约束
- 纯前端实现（HTML + CSS + JavaScript）
- 零外部依赖（不引入任何框架或库）
- 单文件部署

## 用户故事

1. 作为一名学生，我想要快速添加作业及其截止日期，以便记录所有待完成的任务
2. 作为一名学生，我想要看到按截止日期排序的作业列表，以便优先处理最紧急的作业
3. 作为一名学生，我想要标记作业为已完成，以便区分已完成和未完成的任务
4. 作为一名学生，我想要置顶重要作业，以便它们不被淹没在列表中
5. 作为一名学生，我想要搜索特定作业，以便在作业多时快速找到
6. 作为一名学生，我想要数据被自动保存，以便关闭浏览器后不丢失记录
